# КТ Практикум

Тренажёр для подготовки к контрольным точкам. В готовом курсе «КТ № 3 по ВКН» шесть тем, 74 термина и 11 задач, в том числе упражнения на 1НФ и 2НФ.

**[Открыть тренажёр](https://artemcrytw-sketch.github.io/kt-praktikum/)**

## Подготовка к КТ

- **Лекция.** Читай короткие объяснения с примерами и отмечай пройденные темы.
- **Практика вслепую.** Вспомни определение и переверни карточку. В письменном режиме запиши ответ своими словами. Сложные термины можно отправить на повторение.
- **Задачи.** Запиши ход решения, открой подсказки при необходимости и сверься с разбором.

## Как добавить свой курс

Открой **«Новая КТ»** и выбери, как собрать курс.

1. **Из файлов.** Загрузи TXT, Markdown, DOC, DOCX или PDF с текстом. Можно также вставить конспект. Тренажёр извлекает темы и определения по структуре текста. Формат «Термин — определение» помогает выделить карточки. Сканы сначала нужно перевести в текст.
2. **С нейросетью.** Нажми **«Выбрать нейросеть»** и скопируй готовый запрос. Открой ChatGPT, Claude, Gemini, Алису AI или другой чат, прикрепи туда свои материалы и отправь запрос. Вставь ответ в тренажёр или загрузи полученный `course.json`.

В тренажёре нет регистрации и API-ключей. Если выбранный чат просит войти, входи на его сайте под своим аккаунтом. Материалы передаются нейросети только тогда, когда ты сам отправляешь их в её чате. Курсы и отметки в тренажёре сохраняются в браузере для текущего адреса сайта.

## Как открыть на компьютере

Открой `dist/index.html` в браузере. Для импорта PDF запусти локальный сервер. Понадобится Node.js.

```sh
node preview.cjs
```

Затем открой [локальную версию](http://127.0.0.1:4173/).

## Как устроен проект

- [`dist/`](dist/) содержит HTML, CSS и JavaScript. Для запуска сайта ничего собирать и устанавливать не нужно.
- [`dist/course.js`](dist/course.js) содержит готовый курс по ВКН. В [`dist/importer.js`](dist/importer.js) описаны правила импорта, а в [`dist/ai-course.js`](dist/ai-course.js) находится запрос для чат-ботов.
- [GitHub Actions](.github/workflows/pages.yml) проверяет JavaScript и публикует папку `dist` при обновлении ветки `main`.
- Оформление использует тёплую кремовую основу, терракотовый акцент и золотистые карточки. Иллюстрация на главной рисуется в браузере.
