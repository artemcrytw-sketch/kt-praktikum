# КТ Практикум

Тренажёр для подготовки к контрольным точкам. В готовом курсе «КТ № 3 по ВКН» шесть тем, 74 термина и 11 задач, в том числе упражнения на 1НФ и 2НФ.

**[Открыть тренажёр](https://artemcrytw-sketch.github.io/kt-praktikum/)**

## Подготовка к КТ

- **Лекция.** Выбирай тему в оглавлении и переходи к нужному разделу. В конспекте можно раскрыть шаги, посмотреть таблицу или схему и ответить на вопрос для самопроверки.
- **Практика вслепую.** Вспомни определение и переверни карточку. В письменном режиме запиши ответ своими словами. Сложные термины можно отправить на повторение.
- **Задачи.** На широком экране условие видно рядом с ответом. На узком экране переключайся между вкладками «Условие», «Ответ» и «Разбор». Пиши, заполняй таблицы или рисуй, затем сверься с образцом.

Тренажёр запоминает последнюю открытую тему и задачу отдельно для каждого курса. Адрес выбранной темы, раздела или задачи можно скопировать из строки браузера.

Чтобы прикрепить скрин, открой кнопку добавления фото под разделом, условием, своим ответом или разбором. Выбери файл или вставь его из буфера обмена. Рисунки и вложения сохраняются в текущем браузере.

## Как добавить свой курс

Открой **«Новая КТ»** и выбери, как собрать курс.

1. **Из файлов.** Загрузи TXT, Markdown, DOC, DOCX или PDF с текстом. Можно также вставить конспект. Формат «Термин — определение» помогает выделить карточки. Простые таблицы из DOCX и явно размеченные таблицы Markdown отображаются в лекции. Сканы сначала нужно перевести в текст либо прикрепить как изображения к готовому курсу.
2. **С нейросетью.** Нажми **«Выбрать нейросеть»** и скопируй готовый запрос. Открой ChatGPT, Claude, Gemini, Алису AI или другой чат, прикрепи туда свои материалы и отправь запрос. Вставь ответ в тренажёр или загрузи полученный `course.json`. Запрос содержит примеры таблицы, формулы, схемы, кода, шагов и мини-проверки. Для обычного текста достаточно старой структуры курса.

В тренажёре нет регистрации и API-ключей. Если выбранный чат просит войти, входи на его сайте под своим аккаунтом. Материалы передаются нейросети только тогда, когда ты сам отправляешь их в её чате. Курсы и отметки в тренажёре сохраняются в браузере для текущего адреса сайта.

## Как открыть на компьютере

Открой `dist/index.html` в браузере. Для импорта PDF запусти локальный сервер. Понадобится Node.js.

```sh
node preview.cjs
```

Затем открой [локальную версию](http://127.0.0.1:4173/).

## Как устроен проект

- [`dist/`](dist/) содержит HTML, CSS и JavaScript. Для запуска сайта ничего собирать и устанавливать не нужно.
- [`dist/course.js`](dist/course.js) содержит готовый курс по ВКН. В [`dist/importer.js`](dist/importer.js) описаны правила импорта, а в [`dist/ai-course.js`](dist/ai-course.js) находится запрос для чат-ботов.
- [GitHub Actions](.github/workflows/pages.yml) проверяет JavaScript и публикует папку `dist` при обновлении ветки `main`. Источник в **Settings → Pages → Source** должен быть **GitHub Actions**.
- [Блоки](dist/content-blocks.js) показывают учебные данные. Для LaTeX используется локальная копия [KaTeX](dist/vendor/katex/LICENSE).
- [Обложки](dist/covers.js) рисуются в браузере по теме курса. При импорте можно явно указать один из вариантов `coverTheme`, перечисленных в запросе для нейросети.
